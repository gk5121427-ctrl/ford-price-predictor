# Ford Car Price Predictor 🚗

An ML-powered web app that predicts the price of used Ford cars in the UK based on car features. Built with Python, Scikit-learn, and deployed on Streamlit Cloud.

## 🔗 Live Demo
[Click here to use the app](https://ford-price-predictor-devqgzzpajr6andvbyeful.streamlit.app/)

## 📌 Project Overview
This project uses a Linear Regression model trained on Ford car data to predict the selling price of a car. Users can input details like model, year, mileage, transmission, fuel type, and tax to get an instant price prediction.

## ✨ Features
- **Interactive UI**: Clean and user-friendly interface built with Streamlit
- **Real-time Prediction**: Get price predictions instantly
- **Multiple Features**: Model, Year, Mileage, Transmission, Fuel Type, Tax, MPG, Engine Size
- **Deployed**: Live and accessible from anywhere

## 🛠️ Tech Stack
- **Language**: Python
- **Libraries**: Pandas, NumPy, Scikit-learn, Streamlit, Pickle
- **Model**: Linear Regression
- **Deployment**: Streamlit Cloud
- **Dataset**: Ford Car Data - UK

## 📂 Files in this Repo
- `app.py` - Streamlit web application
- `model.pkl` - Trained ML model
- `ford.csv` - Dataset used for training
- `car_predict.ipynb` - Jupyter notebook for model training
- `requirements.txt` - Python dependencies
