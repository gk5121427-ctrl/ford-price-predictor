# Ford Car Price Predictor 🚗

Ye ek ML web app hai jo UK me Ford cars ki price predict karti hai.

## Tech Stack
- **Python**: Pandas, Scikit-learn
- **Model**: RandomForest Regressor with Pipeline
- **Frontend**: Streamlit
- **Dataset**: UK Ford Car Sales Data

## Features
- Car ka Model, Year, Mileage, Transmission select karo
- 1 click me estimated price £ me mil jayega
- Fully deployed on Streamlit Cloud

## How to Run Locally
1. `pip install -r requirements.txt`
2. `streamlit run app.py`
